# Documentation vs. Codebase: What We Say We're Building vs. What Exists

**Purpose:** This is a capability-level comparison, not a line-by-line doc-accuracy check (see git history for those fixes). For each capability the documentation describes, this cross-checks the actual source code to classify it as **BUILT** (real, wired-up implementation), **PARTIAL** (real code exists but key pieces are missing, unmounted, or disconnected), or **NOT BUILT** (aspirational — no corresponding code, or only a plan document).

**Methodology:** Every row below was verified by reading the actual source referenced in the Evidence column — not by trusting another doc's claim about it.

## Overall Positioning vs. Reality

Top-level docs (`tais_frontend/README.md`, `archive/outdated/NORTH_STAR.md`) pitch TSO/TAIS as a "Digital Homesteading" platform for user-owned, privacy-first AI agents: an interview-driven no-code agent builder, backed by a blockchain-verified skill registry with cryptographic trust scoring, NFT-gated tiers, $THINK token staking economics, encrypted private/public RAG the user controls, and "RCRT" as a local context-sovereignty layer that syncs to other apps via OAuth.

If you only read the code, the actual product is narrower but mostly real: a working wallet-authenticated web platform (Express/Prisma registry + React/Vite frontend) with a genuinely functional guided-discovery agent builder, private/public RAG, OAuth-based cross-app agent portability, and a real RCRT local-sync layer (Rust binary + Electron desktop shell). But the "trust economy" (skill security scanning, trust-score computation, audit submission, a CTO agent assistant) is real, implemented code that's simply never wired up to anything live — and essentially the entire "$THINK token tier/staking/subscription" monetization layer described in the vision docs is absent from the web platform (a disconnected, lower-fidelity on-chain balance/staking reader exists only in the separate Electron desktop app, not integrated with the registry's tier system).

## Rollup

**12 BUILT · 6 PARTIAL · 5 NOT BUILT** (out of 23 capabilities catalogued)

The pattern: the *product* layer (agent builder, RAG, RCRT sync, cross-app portability) is real and substantially delivered. The *trust/security* layer (scanning, audits, trust scores, sandboxing) is real code that was written but never connected to the running server. The *monetization* layer ($THINK staking, subscriptions) was designed in detail across two engineering docs and never built at all in the web platform.
